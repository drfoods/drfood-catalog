# 디알푸드솔루션 2026 전자 카탈로그

업로드된 원본 16페이지 PDF를 기반으로 만든 **정적 웹 전자책(Flipbook)** 입니다.

## 포함 기능
- PC: 좌우 2페이지 책 펼침 보기 + 실제 페이지 넘김 애니메이션
- 모바일: 1페이지 보기 + 좌우 스와이프
- 좌측 목차, 전체 페이지 썸네일, 페이지 확대, PDF 다운로드, 현재 페이지 링크 공유
- 별도 호스팅 서버·데이터베이스·웹 프레임워크 없이 작동
- 외부 라이브러리/웹폰트 의존성이 없어 GitHub Pages에서 바로 사용 가능

## 사용 방법
1. 압축파일을 풀고 `index.html`을 웹브라우저에서 열면 먼저 확인할 수 있습니다.
2. PC에서는 좌우 화살표 키나 양쪽 버튼으로 책장을 넘깁니다.
3. 페이지를 클릭하면 글씨와 제품사진을 확대해 볼 수 있습니다.

## GitHub Pages 게시 방법
1. GitHub에 로그인하고 새로운 **Public** 저장소를 생성합니다. 예: `drfood-catalog`.
2. GitHub 저장소에 ZIP 파일 자체가 아니라 **압축을 풀어 나온 내용**을 업로드합니다. 루트에 반드시 `index.html`, `catalog.pdf`, `assets/` 폴더가 있어야 합니다.
3. 저장소의 **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택합니다.
4. `main` 브랜치와 `/ (root)` 폴더를 선택한 뒤 Save를 누릅니다.
5. 웹주소는 보통 `https://GitHub아이디.github.io/drfood-catalog/` 형식입니다. (실제 주소는 저장소 Pages 설정 화면에서 확인.)
6. 아임웹 홈페이지 메뉴 또는 버튼에 위 주소를 연결하고 거래처에는 같은 링크를 공유하면 됩니다.

> GitHub Pages는 공개 카탈로그용입니다. 납품단가·미공개 견적·영업비밀 등은 올리지 마세요. Public 저장소에 포함된 원본 PDF와 제품 이미지는 누구나 접근할 수 있습니다.

## 수정 방법
- 카탈로그 원본을 새 PDF로 변경할 경우 `catalog.pdf`를 교체하고, 해당 페이지의 `assets/pages/pXX.jpg`와 `assets/thumbs/tXX.jpg`도 함께 교체해 주세요.
- 전체 페이지 수가 바뀌면 `index.html` 스크립트의 `count`, `pageLabels`, `pagePairs`, 목차 정보를 업데이트해야 합니다.
- 이미지가 너무 큰 경우 JPEG 파일을 웹용으로 최적화하세요.
